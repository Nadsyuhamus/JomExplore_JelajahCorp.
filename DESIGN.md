# JomExplore Design System

## Overview

JomExplore uses a restrained, daylight-friendly product interface. Visual design supports trip planning rather than competing with it.

## Color

- Primary teal: `#0f766e`
- Primary pale: `#ecfdf5`
- Quiet surface: `#f6fbf9`
- Main text: `#1f2937`
- Strong text: `#1e293b`
- Muted text: `#64748b`
- Border: `#e2e8f0`
- Control border: `#cbd5e1`
- Warning surface: `#fff7ed`
- Warning text: `#9a3412`

## Typography

Use Arial or the system sans-serif stack. Maintain compact product hierarchy, readable body text, and bold labels for important controls and itinerary metadata.

## Shape and Elevation

Controls use 9 to 12 pixel radii. Primary actions may use pill shapes where already established. Panels use light borders and restrained neutral shadows.

## Layout

Primary planner content uses a maximum width of 1180 pixels. Responsive breakpoints reorganize columns and actions at approximately 800 and 520 pixels.

## Components

Reuse the existing navbar, primary and secondary buttons, form controls, place rows, summary strip, map panel, numbered timeline, journey controls, dialogs, and accessible empty states.

## Interaction

Use visible hover and focus states. Motion should be limited to brief state feedback and small transform or opacity transitions between 150 and 250 milliseconds.
